## 1. 데이터

[Ultralytics Construction-PPE](https://www.ultralytics.com/blog/missing-ppe-detection-yolo) 2026년 11월판(Ultralytics 8.4.200 이상에 포함)

- 이미지 1,000장, 12개 클래스, 학습 800장 / 검증 200장 고정 분할, 별도 시험 분할 없음
- 장비 클래스와 미착용 클래스가 쌍을 이룹니다 (예: `helmet` ↔ `no_helmet`).
- 미착용 박스는 **장비가 있어야 할 신체 부위**에 칩니다. `no_helmet`은 안전모 없이 보이는 머리입니다. 가려진 머리에는 어떤 라벨도 붙지 않습니다.

**분석 대상 클래스의 정답 박스 수**

| 클래스 | 학습 | 검증 |
|---|---:|---:|
| helmet | 1,282 | 294 |
| no_helmet | 634 | 179 |
| goggles | 612 | 139 |
| no_goggle | 265 | 82 |

`no_goggle`은 검증 박스가 82개로 가장 적습니다. 그래서 보호안경 쌍 분석은 보류하고 안전모 쌍을 먼저 분석했습니다.

## 4. 오류 분석

평가 기준은 모든 분석에서 같습니다. **신뢰도 0.25 이상**인 예측만 쓰고, 예측 박스와 정답 박스의 겹침이 **IoU 0.5 이상**이면 정답으로 셉니다. 정답 하나에는 예측 하나만 짝지을 수 있습니다.

**`no_helmet` 정답 179개 판정 결과**

| 판정 | 개수 | 의미 |
|---|---:|---|
| 맞힘 (TP) | 104 | |
| 유효한 연결 없음 (FN) | 63 | 미착용 정답에 맞는 예측을 연결하지 못함. 위치가 어긋난 예측도 포함될 수 있음 |
| 안전모로 착각 (FN) | 12 | 같은 자리에 `helmet` 예측이 있음 |
| 오탐 (FP) | 13 | 같은 클래스의 정답과 유효하게 연결되지 않은 예측 (4-2 참조) |

→ **Recall 0.581, Precision 0.889**

### 4-1. 크기별 미탐률과 교란 변수

처음 계획은 정답 박스 크기를 소·중·대(개수가 같은 3구간)로 나눠 미탐률을 비교하는 것이었습니다. 그런데 크기 구간이 **이미지 출처와 거의 완벽하게 겹쳤습니다.**

| 크기 구간 | `source-` 이미지 | `ultralytics-` 이미지 |
|---|---:|---:|
| 소 | 60 | 0 |
| 중 | 36 | 23 |
| 대 | 0 | 60 |

두 출처는 머리 크기 자체가 다릅니다. 정답 박스 크기(√(박스 넓이 / 이미지 넓이))의 중앙값이 `source-`는 0.013, `ultralytics-`는 0.121로 약 10배 차이가 납니다. 크기만으로 미탐률을 비교하면 **크기 때문인지 출처 때문인지 구분할 수 없습니다.** 그래서 출처별로 나눠 다시 봤습니다.

| 출처 | 크기 | 개수 | 미탐률 |
|---|---|---:|---:|
| `source-` | 소 | 60 | **0.850** |
| `source-` | 중 | 36 | 0.556 |
| `ultralytics-` | 중 | 23 | 0.130 |
| `ultralytics-` | 대 | 60 | 0.017 |

**해석**
- **크기별 경향:** 같은 파일명 그룹 안에서도 작은 구간의 미탐률이 높았습니다 (0.85 → 0.56, 0.13 → 0.02). 다른 장면 조건도 달라 크기의 인과 효과를 확정하지는 않습니다.
- **그룹별 경향:** 같은 "중" 구간에서도 `source-`(0.56)와 `ultralytics-`(0.13)의 미탐률이 달랐습니다. 같은 구간 안의 크기 분포도 다를 수 있습니다.
- **크기 지표 주의:** 0.013은 이미지 폭 대비 머리 너비가 아니라 √(박스 넓이 / 이미지 넓이)입니다. 실제 픽셀 크기는 원본 종횡비와 리사이즈 비율까지 확인해야 하므로 8 px로 단정하지 않습니다.

> **주의:** 칸마다 표본이 23~60개로 작습니다. 같은 "중" 구간 안에서도 크기 분포가 다를 수 있어 출처 효과가 다소 부풀려졌을 수 있습니다. `source-`가 실제 현장 사진이라는 점은 육안으로 판단한 추정입니다.

### 4-2. 오탐 13건 재검토

기존에는 `no_helmet` 정답과의 IoU만 확인했습니다. 같은 클래스와 IoU가 0이어도 `helmet` 정답과 겹칠 수 있어, 다른 클래스의 정답도 확인했습니다.

| 관찰 내용 | 예측 수 | 처리 |
|---|---:|---|
| helmet 정답과 일부 겹침 | 5 | 이 중 3건은 helmet과 IoU 0.5 이상. 클래스 혼동 여부를 이미지와 함께 검토 |
| no_helmet 정답과 IoU 약 0.440~0.489 | 4 | 박스 범위 차이 사례. FP 유지 |
| no_helmet 정답 박스가 몸까지 넓게 잡힌 사례 | 2 | 같은 이미지의 두 예측. 라벨 범위 의심으로 기록하고 원본 라벨 유지 |
| 이미 연결된 정답 주변의 추가 예측 | 1 | 중복 후보. 1:1 평가에서 FP 유지 |
| 겹치는 머리 정답이 없는 작은 영역 | 1 | 판독이 어려워 라벨 누락·실제 오탐 판단 보류 |

위 표는 이미지 검토 결과입니다. 자동 분류는 IoU 기준으로 후보를 나누는 용도이며, 오류 원인을 확정하지 않습니다. IoU는 반올림 전 값으로 판정합니다. 기존의 `FP=13`을 줄이기 위해 기준이나 라벨을 바꾸지 않았습니다.

박스 모양의 중앙값만으로 전체 라벨의 일관성을 확정할 수는 없습니다. 의심 사례는 따로 기록했습니다. 자세한 근거와 대표 사례는 [이번 주 점검 기록](docs/weekly/2026-11-24.md)에 있습니다.

### 4-3. 사례 이미지에서 보인 경향 (육안 관찰, 검증 전)

- **안전모로 착각한 미탐:** 니트 비니나 후드처럼 **머리를 덮는 다른 모자**를 쓴 경우가 보입니다. 모델이 "머리에 뭔가 씌워져 있음"을 안전모로 받아들인 것으로 보입니다.
- **위치 어긋남 오탐:** 정답 박스는 머리와 **얼굴 전체**를 감싸는데, 모델 박스는 **머리 윗부분** 쪽으로 치우친 경우가 반복됩니다. 같은 머리를 다르게 정의한 차이로 보입니다.

사례 이미지는 [`results/error_cases`](results/error_cases)에 있습니다. 파일 이름의 `fn_miss`는 유효한 정답 연결 없음, `fn_helmet`은 안전모로 착각, `fp_*`는 오탐(뒤의 한글은 4-2의 유형)입니다.
